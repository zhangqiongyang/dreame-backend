# 微信小程序登录配置

AppID 须与 `dreame-web-mini/src/manifest.json` → `mp-weixin.appid` **完全一致**。

## 1. 后端 `dreame-backend/.env`

```env
WECHAT_APPID=你的AppID
WECHAT_SECRET=你的AppSecret
WECHAT_MOCK=false
```

修改后**重启** uvicorn。启动时终端应打印一行（`print` + 日志）：

```text
微信登录: 正式模式 appid=wxa0aa65…
```

也可用浏览器或 curl 检查：

```bash
curl http://127.0.0.1:8000/health
# 期望: {"status":"ok","wechatLogin":"production","wechatAppId":"wxa0aa65…"}
```

若 `wechatLogin` 为 `mock`，说明环境变量未加载、`WECHAT_MOCK=true` 或 Secret 为空。

**务必在 `dreame-backend` 目录启动后端**（或依赖已修复的绝对路径 `.env`），从仓库根目录 `zhuimi/` 直接启动会读不到 `.env` 而误走 Mock。

## 2. 微信公众平台

登录 [微信公众平台](https://mp.weixin.qq.com/) → 开发 → 开发管理 → 开发设置：

| 配置项 | 说明 |
|--------|------|
| AppID / AppSecret | 与 `.env` 一致 |
| 服务器域名 request 合法域名 | 生产须 **HTTPS**，如 `https://api.yourdomain.com` |
| 本地调试 | 开发者工具勾选「不校验合法域名」；`manifest` 已设 `urlCheck: false` |

## 3. 小程序 `VITE_API_BASE_URL`

`dreame-web-mini/.env.development`：

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

真机预览时改为本机局域网 IP 或内网穿透地址，并在微信后台加入该域名。

## 4. 验证

1. 启动后端：`uvicorn app.main:app --reload --port 8000`
2. 开发者工具打开小程序，清缓存后重新编译
3. 打开订单页或登录页，应能静默登录；数据库 `users.openid` 为真实 openid（非 `mock_` 前缀）

## 5. 常见错误

| 现象 | 处理 |
|------|------|
| `登录码无效` | `code` 只能用一次；勿用 curl 重复测同一 code |
| `invalid appid` | 后端 AppID 与小程序 manifest 不一致 |
| `secret` 相关错误 | 检查 AppSecret 是否复制完整、未过期 |
| 仍出现 `mock_` 前缀 openid | 在 `dreame-backend` 目录启动；检查 `/health` 为 `production`；小程序清除缓存后重新登录（旧 Mock 用户不会自动变真 openid） |

## 6. 手机号快速验证（getPhoneNumber）

1. 微信公众平台 → 开发 → 接口设置，开通「手机号快速验证组件」
2. 小程序登录后，在登录页或「我的」页点击「微信授权手机号」
3. 前端将 `getPhoneNumber` 返回的 `code` 提交 `POST /api/v1/auth/phone`（需 Bearer JWT）
4. 后端调用 `getuserphonenumber` 换取手机号并写入 `users.phone`

Mock 模式（未配置 AppID/Secret 或 `WECHAT_MOCK=true`）下会根据 `code` 生成测试手机号，无需真实微信授权。

## 7. 登录与手机号授权（小程序）

1. **已登录** = 微信会话（JWT）+ 已绑定手机号
2. `pages/login/login`：微信一键登录
3. `pages/login/phone`：手机号快速验证（`getPhoneNumber`），**未授权视为未登录**
4. 需登录的操作（下单、订单等）经 `requireLogin` 自动引导上述两步

**退出再登录仍提示「手机号已绑定其他账号」**：通常是数据库里存在多个用户记录（例如早期测试、AppID 变更前的 openid），手机号挂在旧账号上。当前逻辑会在微信验证通过后自动迁移到本次登录账号；若已绑同一号码则直接成功。
