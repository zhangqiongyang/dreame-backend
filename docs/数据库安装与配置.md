# 数据库安装与配置（MySQL 8 · 教学）

面向：**前端转后端**、第一次在本地或 Docker 里跑 MySQL。  
目标：你能 **装起一个 MySQL**、**建好库和用户**、**用连接串连上 FastAPI（dreame-backend）**。

---

## 一、为什么选 MySQL 8 + utf8mb4

- **MySQL 8**：生态成熟，云厂商托管多，资料多。  
- **utf8mb4**：完整 Unicode（含 emoji），电商商品文案更省心。  
建库建表时统一用 **utf8mb4 / utf8mb4_unicode_ci**（或 `utf8mb4_0900_ai_ci`，与团队规范一致即可）。

---

## 二、安装方式选型（推荐顺序）

| 方式 | 适合谁 | 优点 |
|------|--------|------|
| **A. Docker 跑 MySQL** | 想快速统一环境、少污染本机 | 一条命令起服务、版本固定 |
| **B. macOS Homebrew 安装** | 你常用 Mac、想本机长期有一个 MySQL | 不依赖 Docker |
| **C. 云 RDS（腾讯云等）** | 已买云服务器 / 要联调预发 | 接近生产、备份运维省心 |

下面 **A、B 会写具体操作**；C 只给检查清单（控制台因厂商而异）。

---

## 三、方式 A：Docker 安装 MySQL（推荐开发）

### 1. 前提

- 已安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)（Mac）或 Docker Engine（Linux）。

### 2. 使用本仓库自带 Compose（最简单）

在 **`dreame-backend` 目录**执行：

```bash
docker compose up -d db
```

默认会拉起 **MySQL 8.0**（`mysql:8.0` 镜像），并创建：

- 库名：`dreame`
- 用户：`dreame` / 密码：`dreame`（仅开发用，**勿用于生产**）

### 2.1 若拉取镜像报错 `403 Forbidden`（镜像站问题）

你本机 Docker 可能配置了国内镜像（例如 `dockerhub.azk8s.cn`），该站对个别 tag 会返回 **403**，与 Compose 写法无关。

**处理思路（任选其一）：**

1. **改 Docker 镜像配置**（推荐）  
   - Docker Desktop → **Settings** → **Docker Engine**  
   - 检查 `registry-mirrors`：若包含已失效或限流的地址，可**暂时删除**整段 `registry-mirrors`，保存并 **Apply & Restart**，再执行：  
     `docker compose pull db && docker compose up -d db`  
   - 或换成你公司/阿里云提供的**可用**镜像加速地址（以当前文档为准）。

2. **命令行直连官方库试拉**（用于判断是不是镜像问题）  
   ```bash
   docker pull mysql:8.0
   ```  
   若直连成功，再 `docker compose up -d db`。

3. **不用 Docker，改用本机 MySQL**  
   见下文 **方式 B（Homebrew）**，不依赖镜像站。

本仓库已将 Compose 中镜像从 `mysql:8.4` 调整为 **`mysql:8.0`**，一般更容易被镜像站缓存命中；若仍 403，请按上面第 1 步调整 Docker Engine。

### 3. 验证能否连上

```bash
docker compose exec db mysql -udreame -pdreame -e "SELECT VERSION();"
```

> 说明：容器内 root 密码为 `rootdev`（仅开发）；业务连接请用用户 `dreame`。

看到版本号如 `8.x` 即成功。

### 4. 填到后端的 `DATABASE_URL`

见项目根目录 **`.env.example`** 中的示例（`mysql+aiomysql://...`）。

## 四、方式 B：macOS 用 Homebrew 安装 MySQL

### 1. 安装

```bash
brew install mysql
```

### 2. 启动服务

```bash
brew services start mysql
```

### 3. 首次登录（本机 root 常无密码或随机密码）

```bash
mysql -u root
```

若提示认证失败，可查 MySQL 8 文档使用 `mysql_secure_installation` 或重置 root。

### 4. 创建业务库与用户（在 `mysql>` 里执行）

下面示例与 Docker Compose 一致，便于你复制粘贴学习（**生产请改强密码**）：

```sql
CREATE DATABASE dreame CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER 'dreame'@'%' IDENTIFIED BY 'dreame';
GRANT ALL PRIVILEGES ON dreame.* TO 'dreame'@'%';
FLUSH PRIVILEGES;
```

退出：`exit`。

### 5. 验证

```bash
mysql -udreame -pdreame -e "USE dreame; SELECT DATABASE();"
```

### 6. 连接串（给 FastAPI / SQLAlchemy 用）

异步驱动常用 **aiomysql**，URL 形态：

```text
mysql+aiomysql://dreame:dreame@127.0.0.1:3306/dreame?charset=utf8mb4
```

写入 `dreame-backend/.env` 的 `DATABASE_URL`。

## 五、方式 C：云上 MySQL（RDS / TDSQL-C 等）——检查清单

在控制台完成即可（具体按钮以厂商文档为准）：

1. 创建 **MySQL 8** 实例，网络与你的 API 服务器 **同 VPC 或可访问**（安全组放行 **3306** 或内网端口）。  
2. 创建数据库 **`dreame`**，字符集 **utf8mb4**。  
3. 创建专用账号，**只授权 `dreame` 库**，不要用 root 跑应用。  
4. 把连接地址、端口、用户名、密码拼进 `DATABASE_URL`。  
5. **生产必须 TLS**（云厂商一般提供「SSL 连接」开关与证书路径；后续在应用里配置）。

---

## 六、与 FastAPI（dreame-backend）对齐的检查

1. `.env` 里 `DATABASE_URL` 已设置且 **无多余空格**。  
2. 本机能 `ping` / `telnet` 到数据库端口（云上要开安全组）。  
3. 启动 API：`uvicorn app.main:app --reload`，访问 `/docs`，后续带库的接口不应报「连接拒绝」。  
4. **Alembic 迁移**使用同步 URL时，可用 `mysql+pymysql://...`（本仓库迁移脚本会单独说明；开发期也可先手写建表 SQL 学习，再切迁移）。

## 七、常见问题（排错）

| 现象 | 可能原因 | 处理方向 |
|------|----------|----------|
| `Can't connect to MySQL server` | 服务未启动 / 端口错 / 安全组未放行 | 查 `brew services` 或 `docker compose ps` |
| `Access denied` | 用户名密码错 / 未授权库 | 复查 `GRANT` 与密码 |
| 中文乱码 | 库/表非 utf8mb4 | `SHOW CREATE DATABASE dreame;` 检查字符集 |
| 时区差 8 小时 | 见下文 **「时间与北京时间」** | 区分「库里存的值」和「页面上看的值」 |

### 时间与北京时间（重要）

**本项目的约定：库内直接存北京时间（东八区）**

| 层级 | 规则 |
|------|------|
| 数据库 | `DATETIME` 存的就是北京时间，查表所见即所用 |
| 后端写入 | `now_cn()`；连接时 `SET time_zone='+08:00'` |
| 接口展示 | `format_dt()` 直接格式化，不再做 +8 转换 |

**如何确认 MySQL 时区：**

```sql
SELECT @@global.time_zone, @@session.time_zone, NOW();
```

`NOW()` 应与北京时间一致（例如下午 3 点查就是 15:xx）。

**Docker 开发库：**

`docker-compose.yml` 使用 `--default-time-zone=+08:00`。修改后需：

```bash
cd dreame-backend
docker compose down
docker compose up -d db
```

**本机 Homebrew MySQL：**

```ini
[mysqld]
default-time_zone = '+08:00'
```

**历史数据说明：** 若此前按 UTC 写入，旧记录仍会少 8 小时；只有**新写入**的数据才是北京时间。确认后可用一次性脚本校正（见下），否则只关注新订单即可。

```sql
-- 仅当确认旧数据是 UTC 时执行一次（先备份！）
-- UPDATE orders SET created_at = DATE_ADD(created_at, INTERVAL 8 HOUR), updated_at = DATE_ADD(updated_at, INTERVAL 8 HOUR);
```
