# 教学路线（假支付阶段 · 与 `dreame-backend` 对齐）

你已选择：**MySQL** + **假支付** + **一期微信登录** + **下单传地址（方案 B）**。API 约定：`code` **200 成功 / 500 失败**（见 [后端开发方案-v5](./后端开发方案-v5.md)）。请先完成 **[数据库安装与配置](./数据库安装与配置.md)**，再按天推进。

| 天数 | 目标 | 验收 |
|------|------|------|
| Day 0 | MySQL 可连、`DATABASE_URL` 配置正确 | `docker compose up -d db` 或本机 MySQL 能 `SELECT 1` |
| Day 0.5 | 微信 `code` 登录 + JWT | `POST /api/v1/auth/wechat` 返回 token；带 Bearer 可访问需登录接口 |
| Day 1 | 商品表 + 列表/详情只读 API | 小程序/后台能拉到真实三条商品 |
| Day 2 | 订单创建 → `pending_payment` | 写库成功，金额服务端计算 |
| Day 3 | 假支付 → `paid`（待发货） | 幂等：重复支付不重复改状态 |
| Day 4 | 发货写入物流单号 | 状态 `shipped` |
| Day 5 | 列表筛选 + 超时关单 | 待支付超时变关闭 |

所有代码与迁移放在仓库 **`dreame-backend`**（与旧目录 `zhuimi/backend` 解耦；后者若仍存在，以本仓库为准接 MySQL）。

下一课口令：**「开始 Day1」**——在 `dreame-backend` 落地第一张业务表与 GET 接口。
